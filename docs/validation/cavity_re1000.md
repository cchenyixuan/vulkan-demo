# 2-D 顶盖驱动方腔 Re = 1000:v6 求解器与 Marchi et al. (2021) 的对比

- **日期:** 2026-10-03 至 10-05。
- **代码:** v6 求解器为提交 9cde618,另给加载器加了可选项 `numerics.epsilon_squared_factor`(默认值不变,见"三种数值设置")。验证脚本在 `experiment/validation/`,与本文同一提交。
- **硬件:** 两张 RTX 5090(驱动 576.88,PCIe x8/x8)。K = 2 用 device 0 + 1,其中 device 0 同时驱动桌面。
- **运行:**
  - 12 个完成的 run:三种数值设置 × 250²/500²/1000²,加上发布配置的 δρ 变体;
  - 两个 K = 1 run 按用户决定中途停止(见"运行与墙钟时间")。

## 结论

- **发布配置实际算的是 Re_eff ≈ 1170。** h/Δx = 5 时,发布配置的离散粘性算子只给出 0.85 ν(在快照上实测为 0.851–0.856,与分辨率无关)。
  - **来源:** KCG 正则化 ξ = 0.1 贡献 0.92,粘性项分母里的 ε² = 0.01h²(h 为支撑半径)贡献 0.93。
  - **后果:** 极值位置收敛到偏向壁面的值(1000² 上 y(u_min) −0.011、x(v_max) −0.008、x(v_min) +0.005);参考点误差的收敛阶随加密降到 0.3。
- **修正之后,位置对上了。**
  - **改动(用户决定):** 用户确认 ξ = 0.1 是配置失误,先改为 ξ = 0.001;再以 ξ = 0.001、ε² = 0.0025h²(ν_eff ≈ 0.98 ν)作为主系列。
  - **机理得到确认:** 换设置后极值位置的变化,18 项全部落在"实测 ν_eff + 参考解对 Re 的灵敏度"预测的范围内。
  - **主系列 1000²:** 主涡中心离 Marchi 2021 只有 0.0008 L,三个速度极值的位置差都在 0.001 以内。
- **主系列 1000² 的误差:**
  - 参考点相对 L2 误差 u 3.4 %、v 4.0 %(绝对值 0.0108 / 0.0126);
  - L∞ 为 0.0156 / 0.0198;
  - 收敛阶 0.47–0.65。
  - 发布配置的相对 L2 是 5.0 % / 4.5 %。
- **剩下的是主涡整体偏弱:**
  - **幅度:** 1000² 上 ψ_min 弱 4.0 %,三个速度极值弱 3.8–4.1 %;误差的形状就是整条剖面按比例缩小。
  - **与设置无关:** 它与 ξ、ε 和坐标框架基本无关。
  - **收敛很慢:** 随分辨率约按 0.5–0.65 阶减小,三点外推的极限仍弱约 2.3 %。
  - **原因本文没有确定。**
- **其他检查:**
  - 所有 run 的不变量为 0;稳态在 t ≈ 70–81 达到。
  - float32 ρ 与 δρ 的结果在第三位上相同。
  - 单卡与双卡(K = 1 对 K = 2)的比较按用户决定没有做完。

所有比较都用 **T_c**(Richardson 外推的收敛值,原文的最佳估计)。它们的不确定度(≤ 1.2×10⁻⁸)比本文的 SPH 误差小 5 个量级以上,可以当作精确值。

**原文的边界条件**(第 041004-1 页图 1 与引言、第 041004-2 页第 3 节):单位正方形,原点在左下角,顶盖 y = 1 以 u = 1、v = 0 向 +x 运动,其余三面 u = v = 0;顶盖速度均匀、不做正则化("singular driven cavity",两个顶角处速度从 1 跳到 0),原文没有特殊的角点处理。流函数由从底壁向上累加体积通量得到(ψ = 0 在底壁,u = ∂ψ/∂y),主涡为负值。

**与本文设置的一致性:** 一致。我们的顶盖粒子覆盖整个流体宽度、速度 u = 1(均匀、不正则化),侧壁与底壁粒子静止;两个顶角处速度在顶盖最后一列与侧壁第一列之间从 1 跳到 0(由核宽度抹开,宽度随分辨率缩小),对应原文的奇异角点。不一致的只有 O(Δx) 量级的几何定义(壁面位置,见下文"坐标框架")。

### 三种数值设置

本验证一开始按 v6 发布配置运行。分析中发现,发布配置的离散粘性算子只给出约 0.85 ν(见"粘性算子的有效粘度")。原因有两个,都不随分辨率变化:

- **KCG 正则化:** 修正矩阵的 Tikhonov 项 ξ = 0.1;
- **粘性项分母:** 其中的 ε² = 0.01h²,h 为支撑半径。

接下来的两次改动都由用户决定:

1. 用户确认 ξ = 0.1 是配置失误,改为 ξ = 0.001。
2. 250² 的对照显示 ε 也应一起修正,于是用户又决定以 ξ = 0.001、ε² = 0.0025h²(即 0.01·(h/2)²)作为主系列。

两次改动的依据都是让离散算子回到 ν_eff ≈ ν(算子一致性),不是拟合参考解。三种设置只有这两个数不同,其余参数和粒子文件完全相同:

| 设置 | ξ | ε² | 实测 ν_eff/ν | 相当于 Re_eff | run |
|---|---|---|---|---|---|
| 发布配置 | 0.1 | 0.01h² | 0.851–0.856 | ≈ 1170 | 250²、500²、1000² × float32 ρ / δρ(K = 2) |
| ξ 修正 | 0.001 | 0.01h² | 0.926–0.931 | ≈ 1075 | 250²、500²、1000² float32 ρ(K = 2) |
| ξ+ε 修正(主系列) | 0.001 | 0.0025h² | 0.976–0.982 | ≈ 1020 | 250²、500²、1000² float32 ρ(K = 2) |

- **ξ 的位置:** 写在各 case.yaml 的 `numerics.regularization.xi` 里。`cases/` 下原有的全部 77 个 case.yaml、生成器 HEAD 版本和 shader 默认值都是 0.1。
- **ε² 的位置:** 原来固定写在 v6 加载器里(0.01h²)。为此给加载器加了一个可选项 `numerics.epsilon_squared_factor`,默认 0.01,不写时行为不变。
- **新设置的算例:** `cases/lid_driven_cavity_2d_n{250,500,1000}_xi0p001[_eps0p0025]/case.yaml`,直接引用基础算例的粒子文件。

报告里"发布配置"的结果保留不动,用来说明这两个数的影响。与 Marchi 2021 的主要比较以主系列为准。

## 求解器配置

v6 发布组合(`docs/seam_audit/v6_opt.md` 推荐表),通过环境变量传入,runner 在导入 v6 之前逐项核对(多一项或少一项都拒绝运行):

```
V6_KEEP_DEPARTED=1  V6_GHOST_LAYERS=2  V6_LEAN_TRANSPORT=1  V6_PACKED_REPLICAS=1  V6_COMPACT_GHOST_LISTS=1
V6_BAND_SLOT_LANES=64  V6_GHOST_POOL_FACTOR=0.29  V6_MIGRANT_POOL_FACTOR=0.05  V6_DEPARTED_FACE_FRACTION=0.8
V6_INIT_SEAM_CLAMP=1  V6_WORKER_COUNT_AWARE=1  V6_SPLIT_TRANSFER_QUEUES=1
δρ 变体另加 V6_DELTA_DENSITY=1
```

其余开关保持代码默认(`V6_CASCADE_FORCE`、`V6_BAND_VOXEL_DISPATCH`、`V6_FAST_SUBMIT` 默认开);生产的 depth-2 流水线、per-direction 同步、pool_safety 1.2、每 1000 步 defrag;验证层关闭(`VK_LOADER_LAYERS_DISABLE=VK_LAYER_KHRONOS_validation`)。K = 2 用两张 5090(device 0、1),1:1 切分,seam 在 x = −0.0041(1000²,第 102 / 206 列,离竖直中线 0.82 个支撑半径,所以 u(0.5, y) 的取样跨过 seam);K = 1 用无头的 device 1(runner 按 UUID 核对)。三种数值设置用的是同一套开关,只有 case.yaml 里的 ξ 与 ε² 不同(见上一节)。

**粘性算子的有效粘度(`experiment/validation/effective_viscosity.py`):** 在每个分辨率发布配置 run 的最后一个快照上,用求解器的核(Wendland C4,支撑半径 h,二维归一化 9/(πh²))、邻居集合(除自身外 r < h 的全部粒子)和快照里的体积 V_j = m/ρ_j,原样重算 `force.comp` 的粘性加速度 Σ_{j≠i} 2(d+2) ν V_j ((v_i − v_j)·x_ij)/(r² + ε²) (M_i + ξI)⁻¹ ∇W_ij。把它作用在无散的二次场 v = (y², 0) 和 (0, x²) 上(精确值 ν∇²v = 2ν),在离壁面 1.5 个支撑半径以外随机取 2 万个流体粒子,取比值的中位数,两个场再取平均,得到 ν_eff/ν。同样的计算对不同的 ξ、ε² 重复,所有设置都在同一批粒子(发布配置的快照)上比较。比值也受粒子分布影响:在 ξ+ε 修正 run 自己的 250² 快照上重算,主系列设置给出 0.981(发布配置快照上为 0.976),ξ = ε = 0 给出 1.001(0.995)。所以这个测量本身有约 0.5 % 的不确定度,与它在三个分辨率之间的变化(0.976–0.982)同量级。另外在 6 万个随机流体粒子上统计修正矩阵 M_i 本身。

## 稳态、取样与比较方法

**运行:** 从静止开始,顶盖在 t = 0 起以 u = 1 运动。runner(`experiment/validation/cavity_runner.py`)在 defrag 边界(流水线已排空)做所有读回;每 0.2 个时间单位(取最近的 defrag 边界)一个样本。每个样本检查不变量(存活粒子总数 = 初始总数、所有 `overflow_*`、`far_migration`、GPU 与主机帧戳错误为 0;每个 defrag 边界也检查),任何违反都使该 run 作废(退出码 3,不自动续跑)。

**稳态判据:** 相邻两个时间窗(每个约 10 个时间单位,取整为样本间隔的整数倍)的窗口平均比较:56 个参考点上的速度(u 28 点、v 28 点)的相对 L2 变化 ‖P̄ₖ − P̄ₖ₋₁‖₂ / ‖P̄ₖ‖₂ < 1×10⁻³,且流体动能的相对变化 |KĒₖ − KĒₖ₋₁| / KĒₖ < 1×10⁻³。稳态时刻 t_s 取第一个满足判据的窗口的终点。分析里再用滑动窗口重算同一判据(每个样本时刻 t 比较 [t − 10, t] 与 [t − 20, t − 10],取此后一直满足的第一个 t),两者都报告。运行在 t_stop = max(100, t_s + 20) 停止(上限 200)。

**时间平均:** 每个 run 的最后 20 个时间单位(约 100 个样本),即稳态之后的窗口。报告平均值、标准差、样本数和标准误差 s.e. = std·√(τ_int/n)(τ_int 为该点时间序列的积分自相关时间)。

**插值:** 线性 MLS(基 [1, Δx/h, Δy/h]),权重 = 求解器的 Wendland C4 核 W(r/h)·V_j,V_j = m_j/ρ_j,支撑半径 h(= 5Δx),用所有粒子(流体、壁面、顶盖);对线性场精确,对光滑场二阶收敛(单元测试 `test_cavity_sampling.py`)。Shepard(Σ w f / Σ w)作为灵敏度对照(它在不规则粒子上有一阶偏差,单元测试里 250² 间距时约 1×10⁻³)。

**取样点:** 原文 Table 20 / 21 的 28 + 28 个点(精确的二进分数),每个样本都取;另在两条中线上各取 1001 个等距点(用于极值)。

**坐标框架:** 求解器的流体格点覆盖 [−0.5, 0.5]²,第一排壁面 / 顶盖粒子在 ±(0.5 + Δx)。把哪个正方形当作原文的单位正方形有 O(Δx) 的差别:
- **壁面行框架(主结果):** 单位正方形 = 最内侧壁面 / 顶盖粒子行的中心线所围的正方形,边长 L = 1 + 2Δx(此前约定的"case 实际大小从真正固定的边界粒子算起");
- **半间距框架(灵敏度):** 单位正方形的边在最内侧壁面行与最外侧流体行的正中间,即 ±(0.5 + Δx/2),L = 1 + Δx;
- **流体框框架(灵敏度):** 单位正方形 = 流体格点 [−0.5, 0.5]²,L = 1。

三种框架都关于腔体中心对称,所以两条中线是同一条物理线,只是沿线位置按比例不同;速度不缩放(U = 1)。壁面行与流体框两种框架在每个样本上直接取样;半间距框架由时间平均后的稠密线做三次样条得到。

**极值:** 时间平均后的 1001 点中线剖面,在离散极值附近用 7 点最小二乘抛物线精化,搜索区间 u_min:y ∈ [0.05, 0.45];v_max:x ∈ [0.05, 0.45];v_min:x ∈ [0.60, 0.99]。

**主涡中心与 ψ_min:** 平均窗口内每个时间单位存一个全场快照;把每个快照的 u 用同样的 MLS 插值到覆盖壁面行的 513 × 513 网格上并做时间平均,再像原文那样从底壁向上沿竖直网格线积分(梯形)得到 ψ(底壁 ψ = 0,主涡为负),在内部(|x|, |y| < 0.3)找最小值并用 5 × 5 邻域的二次曲面精化。

**误差与收敛阶:** 参考点上的逐点误差 e_i = ū_i − T_c,i;L2 = √(Σ e_i² / 28),L∞ = max |e_i|(绝对值,以 U 为单位),相对 L2 = L2 / rms(T_c)。收敛阶 p = ln(e₁/e₂) / ln(Δx₁/Δx₂)(相邻两个分辨率)以及三点的最小二乘斜率。

上表是求解器粘性算子的 ν_eff/ν(方法见"求解器配置")。h/Δx 固定时,算子里有两个不随分辨率变化的系数。

**1. KCG 正则化 ξ。**

- **ξ 加在 M 的对角线上。** `experiment/v6/shaders/correction.comp`(第 145–146 行)在 M_i = Σ_{j≠i} V_j (r_j − r_i) ⊗ ∇W_ij 的对角线上加 ξ(case.yaml 的 `regularization.xi`),再求逆。
- **正则化后的逆乘在核梯度上。**
  - `force.comp`(第 203 行起)把它乘到核梯度上,用于压力梯度、粘性项和 PST;
  - `density.comp`(第 185 行起)把同一个修正后的梯度用于连续方程与 δ 扩散。
- **M ≈ 1.129 I,不是 I。** 粒子体积由加载器按 V = 1 / Σ_{j≠i} W 在格点上校准(`experiment/v6/utils/case_loader_v6.py` 第 112 行)。因为求和不含自身项,结果是 V = 1.1293 Δx² 而不是 Δx²。所以在满支撑的区域,M ≈ 1.129 I(下表)。
- **系数 F。** 不加正则化时,KCG 正好把这个倍数除掉;加了 ξ 以后,每个修正后的算子都剩下 F = M (M + ξI)⁻¹:
  - ξ = 0.1 时 F = 1.129 / 1.229 = 0.919;
  - ξ = 0.001 时 F = 0.999。

**2. 粘性项分母里的 ε²。** 粘性项(Monaghan 形式)的分母是 r² + ε²(`force.comp` 第 218–223 行)。发布配置下 ε² = 0.01 h²,h 为支撑半径,即 ε² = 0.25 Δx²;它削弱近邻粒子的贡献,比例只取决于 h/Δx。主系列改为 ε² = 0.0025 h² = 0.0625 Δx²。

**对各项的影响:**

- **压力梯度与连续方程:** 乘以 F 的效果会被压力吸收(压力充当不可压约束的乘子),只把等效声速变成 F·c0,影响是 O(Ma²)。
- **δ 扩散与 PST:** 它们与 h 成比例,随加密消失。
- **粘性项:** 剩下的 ν_eff/ν 不随分辨率改变。所以在 h/Δx = 5 固定、Δx → 0 的极限下,一个 run 逼近的是 Re_eff = 1000 / (ν_eff/ν) 的方腔:
  - 发布配置 ≈ 1170;
  - ξ 修正 ≈ 1075;
  - ξ+ε 修正 ≈ 1020。

两个系数都关掉时,算子在发布配置的快照上给出 0.995–1.003,是一致的。单独看,ξ = 0.1 贡献 0.92(即 F),ε² = 0.01h² 贡献 0.93。

- **剖面差异:** 时间平均剖面最大相差 0.7–2.2×10⁻⁴,rms 为 3.8–9.2×10⁻⁵,是合成标准误差的 1.3–2.3 倍。

- 三种设置在 1000² 的 `n1000_k2_float32*_velocity.png` 和 `*_vorticity.png`;

- **设置的影响:** 改设置只改变了近壁射流带。1000² 上 ξ 修正减发布配置最大 0.019 U,主系列减发布配置最大 0.031 U;主涡核心几乎不变。

## 讨论

### 极值位置的偏差来自有效粘度,已经确认

证据链:

1. **位置偏差不随加密缩小。** 发布配置的极值位置收敛到偏离 T_c 的值,250²–1000² 上 y(u_min) 依次为 −0.010、−0.011、−0.011。与 h 成比例的离散误差会随加密消失(h = 5Δx),所以偏差来自不随 Δx 缩放的东西。
2. **算子本身偏低。** 求解器的粘性算子在快照上的有效粘度只有 0.85 ν,其中 ξ = 0.1 贡献 0.92,ε² = 0.01h² 贡献 0.93,与分辨率无关(见"粘性算子的有效粘度")。
3. **定量吻合。** 用实测的 ν_eff 和参考解对 Re 的灵敏度(Ghia 1982 表格点的粗估),预测换设置后的位置变化。18 个实测值全部落在预测范围内(见"数值设置的影响")。
4. **修正后对上了。** 主系列(ν_eff ≈ 0.98 ν)在 1000² 上极值位置与 T_c 相差不超过 0.001,主涡中心偏 0.0008;三点外推的位置也在 0.001 以内。

本文的数据还排除了以下几种可能:

- **插值方法:** MLS、Shepard、稠密线三次样条给出相同结果。
- **坐标框架:** 框架只能带来 O(Δx) 的移动。
- **稳态是否达到:** 平均窗口内的剩余漂移不超过 3×10⁻⁴。
- **密度存储方式:** float32 ρ 与 δρ 的结果相同。
- **压缩性:** Ma = 0.01,1000² 上 0.01 %–99.99 % 分位的流体粒子密度为 999.988–1000.068,偏离 ρ0 不超过 0.007 %。
- **slab 切缝:** 差值图做了接缝检验,没有发现。

### 剩下的误差:主涡整体偏弱约 4 %

- **形状:** 主系列 1000² 的误差,就是整条剖面按比例偏弱 3–4 %,顶盖附近偏弱得少一些。
- **与设置、框架无关:** ψ_min 的偏弱(1000² 上约 4 %)在三种设置下几乎相同,换坐标框架也基本不变。所以它不是有效粘度的问题,也不是"墙在哪里"的问题。
- **收敛很慢:** 它随分辨率减小,观测阶只有 0.5–0.65;三点外推的极限仍弱约 2.3 %(只当作估计)。
- **可能的方向(都没有排除,需要单独的诊断 run,本文没有做):**
  - h/Δx = 5 的核对顶盖剪切层的平滑。从 T_c 看,顶盖下 0.03 L 内 u 从 1 降到约 0.6;1000² 上 h = 0.005。
  - 顶盖两端奇异角点的处理。
  - PST 与 δ-SPH 在近壁的作用。
  - 粒子存储速度的净平均通量(4–5×10⁻⁴ U)。它太小,单独不足以解释 4 % 的偏弱,但说明粒子的输运速度与存储速度不完全一致。

### 对其他算例的影响

- **默认值:** `cases/` 下原有的全部 77 个 case.yaml、生成器和 shader 默认值都是 ξ = 0.1,加载器的 ε² 默认是 0.01h²。在 h/Δx = 5 下,这些算例的粘性算子都只给出约 0.85 ν。
- **影响范围:** 这只影响粘性物理(Re_eff),不影响性能测量。
- **本次的改动范围:** 只新建了验证用的算例,并给加载器加了一个默认关闭的可选项;原有算例和默认值都没有改。是否把默认值改为 ξ = 0.001、ε² = 0.0025h²,由用户决定。

### 2000²

按用户决定没有跑 2000²,留给集群。粒子数是 1000² 的 4 倍,步数是 2 倍;按 1000² K=2 的每粒子步吞吐外推,在两张 5090 上约 42 h。

## 复现

# 参考值:CSV 的 65 行逐行回到 PDF 的表格里核对(PDF 不入库,见"参考数据")

python utils/geometry/_demo_cavity_case.py --half 125 --out cases/lid_driven_cavity_2d_n250 --no-preview   # 500、1000 同理

# 计划、校准(短跑估算吞吐)、按顺序运行、查看进度
.venv/Scripts/python.exe -m experiment.validation.cavity_campaign plan
.venv/Scripts/python.exe -m experiment.validation.cavity_campaign calibrate
.venv/Scripts/python.exe -m experiment.validation.cavity_campaign run --runs n250_k2_float32,n250_k2_delta   # 运行清单见 RUNS
.venv/Scripts/python.exe -m experiment.validation.cavity_campaign status

# 分析:表格、CSV、图(含流函数;1000² 的流函数每个 run 约十几分钟)
.venv/Scripts/python.exe -m experiment.validation.cavity_analysis
# 只重画图和表(用上一次完整分析的缓存)
.venv/Scripts/python.exe -m experiment.validation.cavity_analysis --from-cache
# KCG 修正矩阵、系数 F 与粘性算子的有效粘度(讨论一节;CPU,几分钟)
.venv/Scripts/python.exe -m experiment.validation.effective_viscosity
# 用 Ghia 1982 的表格点检验换设置后的位置变化(需要上面的 CSV 与 extrema.csv)
.venv/Scripts/python.exe -m experiment.validation.reynolds_sensitivity
# 流场图(CPU,每个 1000² run 约 1 分钟;--frame wall 为本文的主框架)
.venv/Scripts/python.exe -m experiment.validation.cavity_fields --frame wall --jobs n1000_k2_float32 n1000_k2_float32_xi0p001_eps0p0025 --difference n1000_k2_float32_xi0p001_eps0p0025 n1000_k2_float32
