## 结论

b 的差和噪声底同量级：第 10、100、500 步，两组数据的两个分量，b 对 a1 的 56 点最大差与 a1 对 a2 之比都在 0.65–1.53 之间。

缝上的点没有超出噪声。同样 28 个缝上点，b 对 a1 与 a1 对 a2（K = 1 没有缝）的最大差之比在 0.60–1.40 之间。缝上 28 点与其余 27 点直接比，方向不固定，而且 K = 1 对也有同样的起伏：第一组第 500 步缝上是其余的 0.88 / 0.87 倍，重复组第 500 步是 2.35 / 2.01 倍，同组 K = 1 对在同样的点上是 1.70 / 1.75 倍；第一组第 10 步 Δu 是 2.40 倍，K = 1 对是 2.34 倍。没有缝的 K = 1 对也出现同样的差别，所以它不是缝造成的。

分辨力：比值本身散布到约 1.5 倍（每组只有一对 K = 1，b 对 a1 与 a1 对 a2 共用 a1），这个检查分辨不了 1.5 倍以内的缝效应。
