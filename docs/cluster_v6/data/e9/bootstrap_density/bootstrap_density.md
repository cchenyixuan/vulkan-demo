# 启动步多积分一步密度：测量

由 `docs/cluster_v6/scripts/e9_bootstrap_density.py table` 生成。old = v7-rc4 的 `experiment/v7`，new = 修复分支。

## 结论

问题属实，已修，但理由是一致性，不是精度。论文已用的数据不需要重跑。

- 问题：旧代码在融合 / 非融合、深壁跳过开 / 关、传输拷贝、K = 1 / 2、simple / adami 共 15 个组合上结果相同：26 个流体粒子被改动，全部在上角 2h 以内，最大 |ρ−ρ0|/ρ0 = 7.913e-4，最大压力 7,932 Pa = 7.9 ρ0U²；n250 与 n1000 数字相同（h/Δx 和 CFL 相同）。a^0 的最大值也被它主导：simple 215 → 38.7，adami 381 → 77.5（n250），adami 1615 → 1240（n1000）。
- 修复：方案 A（启动步不做 scratch → primary 拷贝，用一个 compute 屏障替代）。15 个组合启动后流体 ρ = ρ0、流体和壁 P = 0。
- 残留检查：defrag 不迁移 scratch，所以第 1 步看到的 scratch 无论如何都是过期且错位的，方案 A 没有引入新状态。毒化实测：启动后 scratch 全部写 NaN，16 个组合（含深壁跳过、传输拷贝）跑到第 1200 步，跨一次 defrag，活粒子 NaN 为 0；空槽里的 11,231 / 15,071 个 NaN 说明毒值确实经过了拷贝。方案 B 不需要。
- 量级：差别只在启动瞬间显著。流体动能相对差：第 1 步 −46 % / −48 %，第 10 步 −10 %，第 100 步 −3.8e-4 / −7.0e-4，第 1000 步 −2.4e-6 / −9.5e-6；56 点瞬时速度从第 1000 步（t = 0.03）起与噪声底同量级，到 t ≈ 10 仍如此。
- 重启：`restart_init` 从不走 `bootstrap_compute`，所以没有第二次密度积分，也没有第二次半步回退。实测 4 个运行重启后流体的 r、v、ρ、P、a、shift 与检查点逐位相同。adami 壁的 P 不同（K = 1 至 4.9e-4，K = 2 至 0.8 Pa），这是重启时的壁面重算，第一步 force 之前会再算一次；继续 2000 步后与不间断运行的差（≤ 1e-5）在同龄噪声内。
- 未覆盖：GPU 测量只有 2-D。3-D 只有 CPU 上的录制流比较。warm 启动（2000² Re 3200）没有单独测，它走旧启动步且 ρ̇^0 不局限在角上，但同时缺的是整个压力场，这一步密度差不是主要的初始误差。
