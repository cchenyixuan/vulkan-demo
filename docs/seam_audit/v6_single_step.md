# v6 单步测试:缺陷 ×(1) 的真实大小(2026-10-03)

接 [`v6.md`](v6.md)。记号沿用:**×(1)** = C5 force 中 column 0 的 ghost 邻居读到 ρⁿ, Pⁿ(单卡读 ρⁿ⁺¹, Pⁿ⁺¹);LAYERS = 1 的 v5 / (0,1) / (1,1) 都有,(1,2) 修掉。**×(2)** = 发送方 kill 的 migrant 在本步 C2–C5 中缺席;(1,1) 修掉。2000 步审计里 (1,1) 与 (1,2) 不可分;本文从同一个状态出发只走一步(及其后若干步),量出 ×(1) 本身。设计与字节见 [`v6_design.md`](v6_design.md)。

## 结论(TL;DR)

- **×(1) 是确定性的、只在 seam 两侧 column 0 的加速度偏差。** 第 1 步,(0,1) 与 (1,1) 的 column 0 加速度与 K = 1 之差,2-D(1M / 4M,N = 300 / 2000)是 K = 1 两次运行之间求和顺序噪声的 **6.9×10³–1.7×10⁴ 倍**;3-D 1M 是 13–19 倍——3-D 的噪声底本身大且重尾(相对噪声 ~2×10⁻⁴,2-D 是 ~10⁻⁷),中位比 1.9–2.8。其余列在 1 附近,只偶尔出现单个粒子的舍入事件(某次运行里一个粒子的 float32 密度舍入到相邻值,邻居的 a 跟着跳,局部比值可到 10²–10³);这类事件在两次 K = 1 运行之间同样出现,与 seam 无关。(1,1) 两次运行的偏差逐粒子相同(相关系数 2-D ≥ 0.999999995,3-D ≥ 0.9986)。
- **偏差全部来自陈旧的 ρⁿ, Pⁿ。** 用快照里的 ρⱼⁿ, Pⱼⁿ 与 K = 1 第 1 步的 ρⱼⁿ⁺¹, Pⱼⁿ⁺¹ 在 CPU 上重算 column 0 的 force 项(TIC 压力 + Morris 粘性),预测与实测的相关系数 2-D 0.99999999–1.0、3-D 0.996–0.999;实测减预测的残差与噪声同级(2-D 0.5–1.0 倍,3-D 0.9–1.2 倍)。
- **绝对大小:** column 0 的 |Δa| rms 为 2-D 0.009–0.032 m/s²、3-D 0.0007–0.0024 m/s²,即 |a| rms 的 **0.2–1.5 %**;中位数只有 10⁻⁷–10⁻³(偏差集中在身旁有"本步压力变了的 ghost"的粒子上)。
- **大小由 float32 决定。** 每步 seam 两列只有 0.8–3.5 % 的流体粒子 float32 密度变化,都是恰好 ±1 ULP(6.1×10⁻⁵ kg/m³)。GPU 上的 P(ρ) 在 ρ₀ 附近是台阶:ρ₀−2 … ρ₀ 都是 0 Pa,ρ₀+1 与 +2 ULP 都是 2.04 Pa,之后每两个 ULP 跳 ~1.0–1.2 Pa;ρ < ρ₀ 时每个 ULP 约 0.5–0.7 Pa。所以一次 1 ULP 的密度变化让 P 跳 0–2.04 Pa(20–44 % 的情况不变)。3-D 还有壁面 ghost:它们的 ρ 固定为 ρ₀,但 P 每步由积分密度重算,0.6–0.9 % 每步会变,贡献预测偏差 rms 的 13–28 %(2-D 为 0)。seam 处 P 的 rms 只有 1.3–6.3 Pa。×(1) = column 0 晚一步看到这些量化的压力台阶。
- **ρⁿ⁺¹、pⁿ⁺¹ 不受影响,kernel_sum 与 L 在噪声内——与预期一致。** 2-D 除 1M N = 300 远离 seam 的 1–3 个 ±1 ULP 舍入翻转(K = 1 两次运行之间同样有)外逐位相同;3-D 有少数 1 ULP 的差,与 K = 1 两次之间同级。
- **shift 没有可测偏差,与预期不同。** force 只通过 PST 的 min(ρⱼ/ρᵢ, 1) 读邻居密度来算 shift,而且只对 r < Δx 的粒子对(2-D 1.0–1.3 %、3-D 0.13–0.34 % 的 ghost 对);这些对几乎都正好在 r ≈ Δx(|r/Δx − 1| ≈ 10⁻⁷–10⁻²),disorder 的变化只有 10⁻¹⁴–10⁻⁹,在 float32 下小于 main_scalar(≈1.3)的半个 ULP。重建给出的 shift 偏差 10⁻²⁰–10⁻¹⁵,比噪声(10⁻¹¹–10⁻¹⁰)低 5–9 个量级;实测比值 0.41–1.04(2-D 4M 0.41–0.44 是噪声底保守所致,其余 0.95–1.04)。
- **(1,2) 在所有量、所有列都在噪声内**(column 0 加速度 2-D 0.49–1.16、3-D rms 0.9–1.8 / 中位 1.0):×(1) 被消除。**自检通过:** 原 K = 1 run 续走一步与重启走一步之差,与两次 K = 1 重启之间的差同级。
- **×(2) 可以分开:** 越界粒子 2h 内,(0,1) 的 kernel_sum 与 shift 在主矩阵里是噪声的 10–6.6×10⁴ 倍(越界后头几步 2×10³–6.6×10⁴),长程 7–6.8×10³;(1,1) / (1,2) 为 0.55–2.5。
- **×(1) 在 50 步内没有被淹没(与预期不同)。** 发展流(N = 2000)与 3-D 里,典型 seam 粒子与 K = 1 的差随 k 增长(中位比 2-D 1M 1.2 → 6.4×10⁴、4M 0.32 → 6.9×10³、3-D 1.9 → 5.9×10³,k = 1 → 50);rms 比下降只是因为 K = 1 自身的 rms 被少数舍入事件主导。**长程补充(k 到 2000):**发展流里 K = 1 自身的混沌差在 50–500 步内饱和(2-D 1M 100–200 步,4M 200–500,3-D 1M 50–100),×(1) 随之落入噪声;年轻流(N = 300)要等 lid 驱动的流动到达 seam,2-D 要 1000–2000 步。饱和后的噪声就是审计的噪声底(2-D 1M rms 0.16–0.18 对审计 0.143 m/s²,4M N = 2000 0.31–0.32 对 0.302)。而 (0,1) 的 ×(2) 在第一次越界后的几百到上千步里,shift / kernel_sum 多数时刻是噪声的数倍到数十倍(最高 66 / 42)。这就是 2000 步审计能看见 ×(2)、看不见 ×(1) 的原因:×(1) 单步很大,但不在 seam 排布上留下持续的印记。

## 方法

### 快照与重启路径

**快照(`single_step.py original`)。** v6 K = 1 从初始条件跑(全局 id 按 seam 审计的办法写进 `extension_fields`),在第 N 步(N = 300、2000)末把每个粒子的 9 个 set-0 SoA 字段原样读回、按 id 排序存盘:

| 字段 | 第 n 步末的含义 | 第 n+1 步谁读 |
|---|---|---|
| `position_voxel_id` | xⁿ(.w = voxel id) | predict(.xyz、.w);correction / density / force |
| `velocity_mass` | v^{n−½}、m | predict(kick 的起点)、density、force;m 进 V_j |
| `density_pressure` | ρⁿ、Pⁿ | density 的连续方程积分 ρ;correction 的 V_j、∇ρ;ghost replica 带 ρ, P |
| `acceleration` | aⁿ | predict |
| `shift` | δrⁿ | predict |
| `material` | 材料组 | 各 kernel 的 kind 门、EOS |
| `correction_inverse`、`density_gradient_kernel_sum` | L、∇ρ、ΣVW | 第 n+1 步先由 correction 重算再读;1 层 replica 照样带过去 |
| `extension_fields` | 全局 id(无物理) | 只给审计用 |

predict 实际读取的是 位置 + voxel id、v^{n−½}、m、a、δr、material(`predict.comp`);ρ 是连续方程积分的状态量(`density.comp` 读 ρⁿ),P 只经 replica 进入邻卡的 force(缺陷 1 本身)。快照之后原 run 不停,继续存第 N+1、N+2、N+5、N+10、N+50 步的状态,作为自检的参照。

**重启(v6 新增,`SphSimulatorV6.restart_init` / `ChainOrchestratorV6.restart_all` / `partition_v6.restart_slab_rows`)。** 把快照按 K slab 的 cut(与正常 K slab 运行同一个分区函数、同一套 cut)用加载器的 x 列判据切开,每个 slab 的行原样上传到 own pid,其余槽和缓冲清零,然后只跑 `initialize_voxelization` 重建 voxel 表(并校验每个粒子都落在 own voxel、alive 数等于行数),再录 step 命令缓冲、做一次 bootstrap defrag(与 `bootstrap_all` 的尾部相同)。**不跑** bootstrap 的 correction / density / force 和 backward half kick:aⁿ、δrⁿ、ρⁿ、Pⁿ、v^{n−½} 全部来自快照,下一帧就是原 run 的第 N+1 步。ghost 不预先填:本帧 phase A 的 ghost_send 与传输照常重建,和每一步一样。

### 运行矩阵

每个算例、每个 N:

| 运行 | K | 说明 |
|---|---|---|
| `original` | 1 | 原 run 续走(自检参照) |
| `k1_a` | 1 | 重启,按 id 顺序上传 → **参照** |
| `k1_b` | 1 | 同上再来一次(原子操作的顺序可能不同) |
| `k1_shuffled` | 1 | 重启,上传顺序随机打乱 → voxel 表内顺序不同 → **噪声底**(同一状态、同一物理、只差浮点求和顺序) |
| `keep0_layers1_t1` | 2 | (0,1) = v5 |
| `keep1_layers1_t1/t2` | 2 | (1,1),两次 |
| `keep1_layers2_t1/t2` | 2 | (1,2),两次 |

每个重启跑 50 帧,在 k = 1、2、5、10、50 步后存状态;K = 2 运行每帧记下每个越过 seam 的粒子(步、id、方向)。主矩阵用的是每帧回读所有 own 粒子的 id(`--migration-tracking ownership`,每帧 50–200 ms);长程补充改为读发送方 staging 里本帧的 migrant 包(`staging`,工具的默认值):每个换 slab 的粒子都要经过一个 migrant 包,两种方法记下的是同一组粒子(同一快照下 (1,1) 与 (1,2) 的长程运行用两种方法记下的越界序列逐个相同),后者是 O(migrant) 的。逐字重现主矩阵要加 `--migration-tracking ownership`。另有长程补充(`<case>_long`,k1_a、k1_shuffled、(0,1)、(1,1)、(1,2) 各一次,k 到 2000),用来看偏差何时被混沌噪声追上。开关:v6 默认(count-aware worker、ghost pool factor 等只影响字节与容量,不影响数值),K = 1 在 device 1,K = 2 在 device 0,1。算例:2-D 1M(`lid_driven_cavity_2d_gen`)、2-D 4M、3-D 1M(`cavity3d_1m`,h/Δx = 4),K = 2 等权 cut。只做正确性。

### 统计

- **按 id 匹配**(单步下所有运行持有同一批粒子,不需要 KD-tree)。只统计流体粒子。
- 列:全局列 c = ⌊(x − x₀)/h⌋,K = 2 的 cut 为 s;无符号距离 d = c − s(c ≥ s)或 s − 1 − c,d = 0 是两侧的 column 0。
- 量:加速度 a、shift δr(向量差的模)、ρⁿ⁺¹、pⁿ⁺¹、kernel_sum、L(对称矩阵差的 Frobenius 范数,非对角元计两次)。
- 每个 bin:test = |X_run − X_k1_a|,noise = |X_k1_shuffled − X_k1_a|;报 rms 比与中位数比,以及 |Δa|/|a| 的 rms 比值与中位数(|a| 太小的粒子不计入中位数)。两者都恰好为 0 记作 "≡"(逐位相同)。
- **越界分组:** 截至该步在任一 K = 2 运行里越过 seam 的粒子为"越界粒子",距其 < 2h 的流体粒子为"越界邻域"(第 1 步 ×(2) 的影响半径:缺邻居的粒子 correction / density 错,force 又读它们);二者从 column 统计中剔除、单独报告,使 ×(1) 不被 ×(2) 污染。
- **CPU 重建(只在 k = 1):** 对每个干净的 column 0 粒子 i,把 force.comp 中与跨 cut 邻居 j 有关的项算两遍——用 j 的 ρⱼⁿ, Pⱼⁿ(快照,即 1 层 replica 带过去的值)和用 ρⱼⁿ⁺¹, Pⱼⁿ⁺¹(K = 1 第 1 步的值),其余量全部取 K = 1 第 1 步的值(第 1 步所有运行的位置、速度逐位相同)。差值就是缺陷 1 的预测 Δaᵢ(压力项 TIC + Morris 粘性项,KCG 修正梯度)与 Δδrᵢ(PST 的 disorder 项)。实测 Δa 减去预测,剩下的应当只剩求和顺序噪声。

### 1.3 shift 为什么没有偏差

force 读邻居密度只有两处:V_j = m/ρ_j(进压力与粘性,不进 shift),以及 PST 的 disorder 因子 (r − Δx)/Δx · min(ρ_j/ρ_i, 1)——它只对距离小于 Δx = 2r 的粒子对起作用(seam 处 2-D 1.0–1.3 %、3-D 0.13–0.34 % 的 ghost 对)。这些粒子对几乎都正好在格点间距上,|r/Δx − 1| ≈ 10⁻⁷–10⁻²,而 ρ_j 的变化至多 6×10⁻⁸ 相对,所以 disorder 的变化只有 10⁻¹⁴–10⁻⁹;在 float32 下这小于 main_scalar(≈1.3)的半个 ULP,GPU 上只能通过偶尔的舍入翻转改变 δr。按同一个(float64)重建,shift 的偏差应为 10⁻²⁰–10⁻¹⁵,噪声是 10⁻¹¹–10⁻¹⁰,低 5–9 个量级;实测 shift 比值 0.41–1.04(2-D 4M 0.41–0.44,噪声底保守,见 1.1;其余 0.95–1.04)与此一致。之后的步里 shift 也没有被带偏:长程表中 (1,1) 的 δr 比值始终 0.4–1.7。没有调任何参数。

- **发展流(N = 2000 起):K = 1 自身的混沌差在几十到几百步内饱和,×(1) 随之落入噪声。** 噪声中位数的跳变点:2-D 1M 在 k = 100–200 之间(6.7×10⁻⁷ → 0.042 m/s²),2-D 4M 在 200–500 之间(2.5×10⁻⁶ → 0.024),3-D 1M 在 50–100 之间(2.3×10⁻⁷ → 4.2×10⁻³)。同一时刻 (1,1) 的 rms / 中位比回到 1 附近:1M 1.36 / 1.57(k = 200)、1.06 / 1.06(500);4M 1.03 / 1.46(500)、1.02 / 0.89(1000);3-D 1.2 / 1.34(100)、1.06 / 1.04(200)。
- **年轻流(N = 300 起):** seam 附近大部分仍静止,K = 1 两次运行在那里的中位粒子逐位相同(但已有 15–46 % 的粒子不同,rms 噪声到 ~0.07 m/s²),直到 lid 驱动的流动到达(2-D 1M 约 k = 500,此时中位比 8×10³、rms 已是 0.9;4M 约 k = 1000,中位比 3.3×10³);之后同样回到 1 附近(1M k = 1000、4M k = 2000)。3-D 的 N = 300 已有流动,与 N = 2000 一样在 k ≈ 100 饱和。
- **饱和后的噪声就是审计的噪声底。** K = 1 自身的 column 0 加速度差:2-D 1M 在 k = 1000–2000 为 rms 0.16–0.18 m/s²(审计 N = 2000:0.143),2-D 4M N = 2000 在 k = 1000–2000 为 0.31–0.32(审计 0.302;N = 300 起的到 k = 1000 尚未饱和,0.13)。
- **转折段(饱和前后)单次比值波动大。** 噪声与被测运行都只有一个样本,中位数正好落在"已偏 / 未偏"的分界上时,同一配置的两次运行可以差几倍(例如 3-D N = 300、k = 50 时 (1,2) 的中位比在主矩阵是 1.35、在长程是 5.7,N = 2000 是 0.2);(1,2) 在整个长程里没有系统性偏离 1。
- **×(2) 不同:它留下持续的印记。** 第一次越界之后的几百到上千步里,(0,1) 的 shift 与 kernel_sum 多数时刻是噪声的数倍到数十倍(三个算例,最高 66 / 42),而 (1,1) 与 (1,2) 一直在 ~1(0.4–1.7)。个别时刻会回落(最低到 1.0 / 1.6,例如 3-D N = 300 的 k = 500、2-D 4M N = 2000 的 k = 2000);k 很大时越界粒子成百上千,2h 的排除区盖住了 seam 列的大部分,"干净"组只剩远离越界的粒子,这是分组的局限。少一个邻居是几何上的错(kernel_sum 少 1.5 %、PST 把粒子往错的方向推),每次越界都重新注入,并在 seam 列的排布上累积;×(1) 只是压力晚一步,方向随机、大小在 ULP 级,不累积成可测的排布差。

## 为什么 2000 步审计看不到 ×(1)

1. 审计比较的是两条从 t = 0 起各自演化 300 / 2000 步的轨迹。到 N = 2000,K = 1 两次运行之间的差早已饱和(2-D seam 列加速度 rms 0.14–0.30 m/s²);单步测试的噪声底是 10⁻⁶ m/s² 量级,两者差 5 个量级。
2. ×(1) 每步注入的偏差(2-D column 0 加速度 rms 0.01–0.03 m/s²)比饱和的混沌差小一个量级,而且在发展流里几十到几百步内就被混沌放大到与之无法区分(年轻流要等流动到达 seam,2-D 约 1000–2000 步);它不像 ×(2) 那样在 kernel_sum / shift / 排布上留下持续的、可测的印记。
3. 所以 (1,1) 与 (1,2) 在审计里不可分(v6.md),但这不说明 ×(1) 小:就单步而言,它是 seam 列上的确定性偏差(2-D 为求和噪声的 10³–10⁴ 倍,3-D 13–19 倍),物理上等于"column 0 晚一步看到邻居的 float32 压力台阶"。要不要为它付 (1,2) 的代价(2-D 性能持平、3-D 8M −2.3 %,见 v6.md),取决于是否需要与单卡逐步一致;对几百步以上的统计量,(1,1) 已经测不出差别。

## 局限

- 每个算例只取两个快照(N = 300、2000),K = 2 等权一个 cut;偏差的绝对大小取决于当步 seam 附近有多少 ghost 的 float32 密度恰好变了一个 ULP(随流场而变,0.8–3.5 %)、3-D 还有多少壁面 ghost 的压力跳了台阶,不同时刻会不同。
- 噪声底是"同一状态、只差求和顺序"的单步噪声,比审计的噪声底(两次 K = 1 从 t = 0 起各自演化的差)小 4–6 个量级:2-D 1M 的 column 0 加速度,审计 N = 300 / 2000 为 rms 0.022 / 0.143 m/s²,单步 k = 1 为 1.3×10⁻⁶ / 7.6×10⁻⁷ m/s²。两者回答的是不同的问题,见上一节。
- 3-D 只有 1M、h/Δx = 4 一个算例;3-D 8M 的 departed 突发(一整排 z 越线)没有在单步里覆盖。
- CPU 重建只覆盖干净的 column 0(2h 内无越界粒子)的 force 项,用 float64 计算;越界邻域里 (0,1) 的 ×(2) 只报了比值。
- 每个配置的噪声、参照与长程各只有一个样本;转折段的单次比值可以差几倍(见结果 2),结论依靠的是多个算例、多个 k 的一致走势与第 1 步的逐粒子重建。
- 单步运行用 v6 默认开关(count-aware worker 关、ghost pool factor 1):这两项只改变传输字节数与容量,不改变数值;审计与性能用的是生产开关。
